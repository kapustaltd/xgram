# Xgram — Telegram Web в интерфейсе X

Неофициальный веб-клиент Telegram, который выглядит и ведёт себя как x.com. Дизайн-токены сняты с x.com (см. [docs/x-reverse.md](docs/x-reverse.md)), данные — настоящий Telegram через MTProto (GramJS) прямо из браузера, без своего сервера.

## Запуск

```bash
pnpm install
cp .env.example .env   # впишите api_id и api_hash с https://my.telegram.org
pnpm dev               # http://localhost:5173
```

Без `.env` доступен **демо-режим** с локальными данными — весь интерфейс работает без входа.

## Что где

| X | Telegram |
|---|---|
| Главная → «Для вас» / «Подписки» | посты всех каналов: по вовлечённости / по времени; новые посты — плашкой «Показать N постов» |
| Пост → ответы | комментарии канала (группа обсуждения) |
| ❤ / 🔁 / 💬 / 📊 / 🔖 | реакция / переслать / комментарии / просмотры / в Избранное |
| Сообщения | личные чаты, группы, боты (раскладка X DMs, отправка текста и файлов, ответы) |
| Уведомления | непрочитанное и упоминания |
| Поиск | глобальный поиск каналов, людей и сообщений; хэштеги |
| Закладки | «Избранное» (Saved Messages) |
| Профиль | профиль канала / пользователя; баннер — размытая аватарка |
| «Актуальное» / «Кого читать» | хэштеги из ваших каналов / рекомендации каналов Telegram |
| «Опубликовать» | отправка в выбранный чат (по умолчанию — в Избранное) |

Вход: по номеру (код + 2FA) или по QR-коду. Сессия хранится в `localStorage` этого браузера.

## Стек

Vite 8 · React 19 · TypeScript · Tailwind CSS 4 · GramJS (`telegram`) · zustand · lucide-react.

```
src/
  tg/types.ts    — общий интерфейс TgApi
  tg/gram.ts     — реализация на GramJS (MTProto over WebSocket)
  tg/demo.ts     — демо-данные
  index.css      — токены X (light/dark)
  components/    — Sidebar, PostCard, Media, Composer, RightColumn…
  pages/         — Home, Explore, Notifications, Messages, Profile, PostThread…
```

## Ограничения

Нет звонков, секретных чатов, редактора стикеров и платежей. Видео показывается превью со ссылкой в Telegram. Отписка от канала — в официальном приложении.
